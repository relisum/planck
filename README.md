# YOUR PERSONAL TRACKER
## Fast start:
1. run `yarn prisma migrate dev --name init`
2. run `yarn prisma generate` in project root directory
3. run `cd client/` and `yarn install`
4. run `cd server/` and `yarn install`
5. add `.env` file in `client/` with `VITE_API_URL`
6. run `start.sh` from project root directory
